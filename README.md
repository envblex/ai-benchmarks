# AI Benchmarks: Frontier Agent & Reasoning Benchmark Suite

フロンティア AI モデルおよび自律エージェントの推論限界・並行制御力・ドメイン設計力・耐欺瞞性を厳密に測定するための高難易度ベンチマーク仕様スイートです。

既存の実務ベンチマーク（SWE-bench 等）がサチュレーションする中で、LLM が本質的に苦手とする「状態空間の爆発」「サイレント障害」「厳密なカーネル/ハードウェア制約」「反例探索」「カモフラージュ看破」を極限まで突いた問題群を収録しています。

## 難易度（Tier）の定義

問題の能力軸（カテゴリ）を維持したまま、以下の 3 段階の難易度（Difficulty Tier）を定義しています。

| Tier | 難易度ラベル | 対象・到達水準 | 想定通過難度 |
|---|---|---|---|
| **Tier 1** | **Intermediate / Math** | 大学教養・数理パズル・標準的な競プロ上位レベル。紙とペンまたはシンプルな探索で解法に到達可能。 | 優秀な人間や推論モデルであれば解法を導出可能 |
| **Tier 2** | **Frontier / Senior** | シニアエンジニア・専門研究者レベル。複雑なドメイン設計、多重制約、非自明なエッジケースを処理。 | 現行フロンティアモデルが数十ステップの試行錯誤で部分点〜完答を狙える境界線 |
| **Tier 3** | **Nightmare / Peak** | 極限のハードウェア/カーネル制約、欺瞞・カモフラージュ、外部ソルバーなしでの組合せ爆発。 | 現行の最上位モデルでも一貫した通過（Pass-all-5）が極めて困難 |

## バージョン別一覧

### [v1: 超難関 AI ベンチマーク 5 領域 25 問](./v1/README.md)

* **配点**: 25 問 × 20 点 = 500 点満点
* **評価指標**: `Score@1` (5 試行平均点) および `Pass-all-5` (5 回連続完全正解率)
* **環境**: Firecracker MicroVM / エアギャップ（ネット完全遮断）/ 外部ソルバー禁止
