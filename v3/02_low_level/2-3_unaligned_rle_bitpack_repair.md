# 問2-3：ビットパッキング・RLE展開エンジンのバイト境界アライメント跨ぎバグ修復

## 1. 課題設定
エッジデバイスからの時系列ログを圧縮するバイナリプロトコルエンジン（`/workspace/codec/`）がある。
特定の可変ビット長（5ビット、11ビット、13ビット）データがバイト境界（8-bit boundary）をまたぐ際に、上位ビットの切り捨てやビットシフト方向の符号拡張ミスにより、展開データが不正な値（Corrupted Data）になるエッジケースが存在する。
エージェントはファジングテストで検出された失敗入力を分析し、ビット演算ロジックを修正して圧縮・展開の完全な可逆性を保証せよ。

## 2. 作業環境
- リポジトリ: `/workspace/codec/`
- テストスイート: `pytest tests/test_codec.py`

## 3. 達成条件
1. 失敗しているテストケース（境界跨ぎビット列のシリアライズ・デシリアライズ）のビット演算トレースを追跡すること。
2. エンディアンおよびアライメント非依存の正確なビットマスク・シフト処理を実装し、バッファオーバーフローを防止すること。
3. 既存テストおよび非公開のランダムファジング入力に対して、エンコード→デコード結果の完全一致（ビット完全性）を実証すること。

## 4. 採点基準（20点満点）
* **8点**：バイト境界をまたぐビットパッキングおよびアンパッキングのバグを正確に修正している。
* **6点**：RLEラン長計算時のオーバーフローおよび空バッファ境界条件を正しく処理している。
* **6点**：Holdoutファジングテスト（10,000パターンのランダムビットストリーム）を全パスする。
