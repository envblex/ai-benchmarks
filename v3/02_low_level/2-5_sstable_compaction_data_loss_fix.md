# 問2-5：追記専用SSTableエンジンにおけるコンパクション時データ消失バグの修正

## 1. 課題設定
LSM-Treeアーキテクチャを採用した組み込みKVS（`/workspace/minikvs/`）において、複数のイミュータブルSSTableファイルを1つに統合するコンパクション（Compaction / Multiway Merge）処理を実行した際、同一キーに対する「Tombstone（削除マーカー）」と「古い値の更新」の順序関係が狂い、削除されたはずのキーが復活したり、最新の書き込み値がサイレントに消失する重大なバグが報告されている。
エージェントはSSTableのマージイテレータとシーケンス番号（またはタイムスタンプ）の比較ロジックを修正し、スパースインデックスの正確性を回復させよ。

## 2. 作業環境
- リポジトリ: `/workspace/minikvs/`
- 再現テスト: `pytest tests/test_compaction.py`（Fail）

## 3. 達成条件
1. 失敗する再現テストをトレースし、コンパクション時にキーの重複排除が行われる際の優先順位判定ミスを特定すること。
2. Tombstoneレコードの生存期間および最新バージョン判定ロジックを修正すること。
3. コンパクション完了後に生成されるSSTableファイルおよびスパースインデックス（Sparse Index）による二分探索読み出しテストをすべてパスさせること。

## 4. 採点基準（20点満点）
* **8点**：コンパクション処理におけるシーケンス番号順のマージおよびTombstone処理の不整合を正確に修正している。
* **6点**：スパースインデックスのオフセット計算およびキー範囲ブロックの二分探索が正しく動作している。
* **6点**：Holdoutクラッシュ・リカバリテストおよびランダムCRUDテストをデータ破損なしでパスする。
