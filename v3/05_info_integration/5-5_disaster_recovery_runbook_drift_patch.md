# 問5-5：災害復旧（DR）計画ランブックとTerraformインフラコードの乖離監査と自動修復PR

## 1. 課題設定
企業の災害復旧計画書（Markdown形式のDRランブック `/workspace/dr/runbook.md`）と、マルチリージョンインフラを管理するTerraformコード（`/workspace/terraform/`）がある。
半年に1度のDR机上訓練を実施したところ、コード側の度重なるアップデートにより、ランブックの手順通りにフェイルオーバーを実行してもセカンダリリージョンが起動しない乖離（Drift）が4箇所存在することが判明した。
エージェントはランブックに記載された復旧目標（RTO 15分, RPO 1分）および手順を精査し、Terraformコードおよびランブック双方の不整合を特定して、整合性を完全に一致させる修正パッチを作成せよ。

## 2. 作業環境
- DRランブック: `/workspace/dr/runbook.md`
- Terraform構成: `/workspace/terraform/` (VPC, RDS, Route53, ECS)
- 検証ツール: `bash scripts/validate_dr_drills.sh`

## 3. 達成条件
1. フェイルオーバー実行時に致命的となる4箇所の不整合（例: レプリカ昇格設定の欠落、セキュリティグループのCIDR不一致、DNSフェイルオーバーTTLの過大値、KMSキーのクロスリージョン暗号化設定不備など）を特定すること。
2. Terraformコードの構成不備を修正し、`terraform validate` をパスさせること。
3. `validate_dr_drills.sh` による自動化されたDR訓練シミュレーションテストを全パスさせること。

## 4. 採点基準（20点満点）
* **8点**：DR実行時に致命的となる構成乖離（Terraform vs ランブック）の4箇所を漏れなく特定している。
* **6点**：Terraformコードおよびランブックの双方が、RTO/RPO要件を満たす正しい実装・記述に修正されている。
* **6点**：HoldoutのDR自動検証シミュレータによるフェイルオーバー自動テストを100%パスする。
