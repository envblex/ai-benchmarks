# 問3-5：共同編集エンジンの3-Way差分マージにおける競合検出漏れ（サイレント上書き）解消

## 1. 課題設定
クラウドドキュメント編集基盤のコアエンジン（`/workspace/diff-merge/`）において、ベースリビジョン（Base）に対して2つのクライアント（Ours / Theirs）が同時に編集を行った際の3-Wayマージロジックが実装されている。
しかし、行内（Intra-line）の隣接する文字変更や、配列要素の並び替えと要素削除が同時に起きた際、競合マーカー（Conflict）を出さずに一方の変更が他方をサイレントに上書き・消去してしまう重大な不整合バグが存在する。
エージェントはマージアルゴリズムのチャンク分割と競合境界判定を修正せよ。

## 2. 作業環境
- リポジトリ: `/workspace/diff-merge/`
- テストスイート: `pytest tests/test_merge.py`

## 3. 達成条件
1. 失敗しているマージケース（非自明な隣接行編集、順序入れ替えと値変更の衝突）の差分ツリーを分析すること。
2. 自動マージ可能な変更（互いに素な行・フィールドの変更）は正しく統合しつつ、真の競合箇所を漏れなくコンフリクトとして検出すること。
3. 意図しないデータのサイレント消失（Data Loss）を0件にすること。

## 4. 採点基準（20点満点）
* **8点**：サイレントデータ上書きが発生していた隣接境界マージロジックを正確に特定・修正している。
* **6点**：コンフリクト不要な安全な差分は正しく自動マージし、不要なコンフリクト（False Positive）を最小限に抑えている。
* **6点**：Holdoutマージテスト（Gitの3-Wayマージ難関テストケース群）を100%パスする。
