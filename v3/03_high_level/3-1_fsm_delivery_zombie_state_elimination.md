# 問3-1：配送追跡FSMの不正遷移・ゾンビ状態引き起こしバグの解消

## 1. 課題設定
EC物流プラットフォームの配送ステータス管理エンジン（`/workspace/delivery-fsm/`）において、非同期Webhookの順序逆転（例: 「配達完了」が「集荷中」より先に届く）が発生した際、ステートマシンが未定義遷移を踏んでゾンビ状態（操作不能）に陥る不具合が発生している。
エージェントはハードコードされた条件分岐（`if-elif` のスパゲッティコード）を保守性の高い明示的状態遷移テーブル（State Pattern / FSM）にリファクタリングし、許容されるべき順序逆転イベントのバッファリングと不正な後退遷移の拒絶を正しく実装せよ。

## 2. 作業環境
- リポジトリ: `/workspace/delivery-fsm/`
- テスト実行: `pytest tests/test_state_transitions.py`

## 3. 達成条件
1. 失敗する順序逆転・不正遷移テストを分析し、現在のステート管理の欠陥を洗い出すこと。
2. 状態（`ORDERED`, `DISPATCHED`, `IN_TRANSIT`, `OUT_FOR_DELIVERY`, `DELIVERED`, `CANCELLED`）間の遷移ルールを宣言的に再構成すること。
3. 既存の全単体テストをパスさせるとともに、非同期メッセージ遅延シミュレーションテストをパスさせること。

## 4. 採点基準（20点満点）
* **8点**：ステートマシンを拡張性のある構造にリファクタリングし、不正な状態遷移を厳格にブロックしている。
* **6点**：順序逆転イベントの再試行・解決ロジックが正常に機能し、ゾンビ状態の発生を防止している。
* **6点**：Holdoutイベントストリームテスト（ランダム順序での10,000件遷移要求）を例外なしで完走する。
