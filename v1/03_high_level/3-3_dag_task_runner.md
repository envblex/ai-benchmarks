# 問3-3：循環参照とエラー伝播をサポートする依存関係タスクランナーの実装

## 1. 課題設定
JSONで定義されたDAGタスク群を受け取り、依存順序を守りながら並列実行するタスクランナーを実装せよ。
循環がある場合は `CyclicDependencyError` を投げ、途中タスクが失敗した場合は下流のみを `SKIPPED` にせよ。

## 2. 採点基準（20点満点）
* **6点**：循環依存を検知して例外を投げ、非循環時はトポロジカル順序に従い最大並列度で実行する。
* **8点**：タスク失敗時のリトライと下流タスクの `SKIPPED` 伝播が正確に動作する。
* **6点**：各タスクの実行ステータスレポートがスキーマ通りに生成される。
