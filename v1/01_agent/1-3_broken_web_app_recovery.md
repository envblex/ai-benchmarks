# 問1-3：起動しないWebアプリケーションの原因特定と復旧

## 1. 課題設定
`/workspace/app/` にあるPython（FastAPI + SQLite）のWebアプリが起動時にエラーで落ちる。原因は以下の3点にある。
1. `.env` ファイル内のデータベースファイルパスが誤っている。
2. 必要なPythonパッケージが1つ仮想環境にインストールされていない（ローカルの `/workspace/wheels/` に `.whl` ファイルがある）。
3. ポート8080がすでに別のダミープロセスによって占有されている。
これらをすべて解決し、ポート8080でアプリを正常起動させ、`GET /health` が `{"status": "ok"}` を返す状態にせよ。

## 2. 期待される状態
- ポート8080でバックエンドアプリが稼働中。
- `curl http://localhost:8080/health` -> `{"status": "ok"}` (HTTP 200)

## 3. 採点基準（20点満点）
* **6点**：ポート8080を占有している不要プロセスを特定（`lsof` や `ss` 等）して停止させている。
* **6点**：ローカルの `.whl` から不足パッケージをインストールし、`.env` のパスを修正している。
* **8点**：評価終了時点でポート8080への `GET /health` リクエストがHTTP 200を返す。
