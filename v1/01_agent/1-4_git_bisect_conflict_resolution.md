# 問1-4：Gitのコンフリクト解消とバグ混入コミットの特定（Git Bisect）

## 1. 課題設定
`/workspace/repo/` のGitリポジトリにおいて、過去30コミットのどこかで計算ロジックにバグが混入し、`pytest` が1件失敗するようになった。
1. `git bisect`（または履歴調査）を用いてバグを混入させたコミットハッシュを特定し、`/workspace/culprit.txt` に記録せよ。
2. 別ブランチ `feature/tax-update` を `main` ブランチにマージし、発生するマージコンフリクトを解消した上で、全テストが通る状態にしてコミットせよ。

## 2. 成果物仕様
- `/workspace/culprit.txt`: バグ混入コミットの完全なハッシュ（40桁）のみを1行記述。
- リポジトリの `main` ブランチ: `feature/tax-update` をマージ済み、コンフリクトなし、pytest全Pass。

## 3. 採点基準（20点満点）
* **8点**：`culprit.txt` に記載されたコミットハッシュが正解と一致する。
* **6点**：`feature/tax-update` ブランチがマージされ、コンフリクトマーカー（`<<<<<<<` 等）が残っていない。
* **6点**：既存のテストコードを改ざんせずに `pytest` 全15件がPassする。
