# 問2-1: 動的メモリアロケーション禁止下での Lock-Free MPMC リングバッファの実装

**カテゴリ**: コーディング性 (低レイヤー)  
**配点**: 20点

## 課題設定

複数のプロデューサーと複数のコンシューマー (MPMC) が同時にアクセスする **固定長リングバッファ** を C++20 または Rust で実装せよ。

## 制約条件

1. 初期化時以降のヒープアロケーション (`malloc`, `new`, `Box` 等) を一切禁止する。
2. `std::mutex` や OS レベルのロックプリミティブの使用を禁止し、アトミック操作 (CAS 等) のみで実装する。
3. ABA 問題を完全に回避する。
4. メモリオーダリングにおいて、不要な `SeqCst` (Sequential Consistency) の乱用を避け、必要な箇所に適切な Acquire / Release / Relaxed を指定する。
5. False Sharing (偽共有) を防ぐため、競合するアトミック変数間のキャッシュライン (64 バイト) 境界アライメントを保証する (`alignas(64)` または `#[repr(align(64))]`)。

## 採点基準 (20点)

- **8点**: 8 スレッド × 8 スレッドで 1,000 万回の `push` / `pop` を行うストレステストにおいて、データの欠損・重複・順序逆転がゼロである。
- **6点**: Acquire/Release セマンティクスで実装されており、デッドロックやライブロックが発生しない。
- **6点**: ThreadSanitizer (TSan) およびモデルチェッカー (Loom 等) による検査で Data Race および ABA バグが検出されない。
