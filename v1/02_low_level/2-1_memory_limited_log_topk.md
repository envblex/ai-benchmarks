# 問2-1：メモリ制限（50MB）下での1GBアクセスログのTop-K集計

## 1. 課題設定
1GBのWebサーバーアクセスログファイル（1行1レコード：`タイムスタンプ IPアドレス パス レスポンスタイムms`）を読み込み、以下を出力するプログラムを実装せよ。
1. アクセス数が最も多い上位10個のIPアドレスとその回数
2. 各エンドポイント（パス）ごとのレスポンスタイムの95パーセンタイル値（1ms単位のヒストグラム法または正確な集計）

## 2. 制約条件
- プロセス全体の最大メモリ使用量を **50MB以下** に制限する。
- 実行時間は10秒以内。

## 3. 採点基準（20点満点）
* **8点**：50MBのメモリ制限内でOOMを起こさず完走する（ストリーム処理・1行ずつの読み込みができている）。
* **6点**：上位10個のIPアドレスと95パーセンタイル値が正解と完全一致する。
* **6点**：1GBの入力に対して10秒以内に処理が完了する。
