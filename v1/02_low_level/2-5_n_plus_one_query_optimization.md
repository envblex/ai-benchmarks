# 問2-5：N+1問題と全件スキャンを解消するクエリ・インデックス最適化

## 1. 課題設定
10万件のユーザー、50万件の注文、200万件の注文明細が入ったSQLiteデータベースと、レスポンスに15秒かかっている遅いレポート集計スクリプト（Python + SQL）が与えられる。集計結果の仕様を一切変えずに、実行時間を **15秒から0.2秒（200ms）以下** に高速化せよ。

## 2. 成果物
- 修正済み集計スクリプト `optimized_report.py`
- 追加したインデックス定義 DDL

## 3. 採点基準（20点満点）
* **8点**：出力される集計結果が元のスクリプトの出力と100%一致する。
* **6点**：N+1クエリが解消され、JOINとGROUP BYを用いた単一（または少数）のクエリに書き換えられている。
* **6点**：適切な複合インデックス（`CREATE INDEX`）が追加され、実行時間が200ms以下に収まっている。
