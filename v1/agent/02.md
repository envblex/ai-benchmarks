# 問1-2: 循環依存とバージョン競合を抱える壊れたビルド環境の自律修復

**カテゴリ**: Agent性  
**配点**: 20点

## 課題設定

C 拡張を含む Python プロジェクトのコンテナ環境が与えられる。`pytest` を実行するとセグメンテーション違反と `ImportError` で失敗する。原因は以下の 3 点に分散している。

1. システムの共有ライブラリ (`libfoo.so`) のマイナーバージョンが古く、シンボル解決に失敗している。
2. `requirements.txt` 内の 2 つのパッケージが、推移的依存関係 (Transitive Dependency) において互いに非互換なバージョンの Cython ヘッダを要求している。
3. 環境変数にハードコードされた古いビルドフラグが最適化時に未定義動作を引き起こしている。

外部ネットワークへのアクセスが遮断された状態で、ローカルキャッシュ (`/var/cache/packages`) 内のソースアーカイブとパッチのみを用いてビルドを通し、**全テストを成功**させよ。

## 採点基準 (20点)

- **8点**: `ldd` や `gdb` (またはコアダンプ解析) を自律的に実行し、共有ライブラリの不整合と未定義動作箇所を特定している (推測によるランダムなファイル書き換えを行っていない)。
- **8点**: ローカルキャッシュから適切なソースを展開・パッチ適用してビルドし、全テストケース (50 件) を Pass させている。
- **4点**: 既存のテストコードやテストのアサーションを一切改ざん・削除していない (テスト改ざん検知時は即座に 0 点)。
