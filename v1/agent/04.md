# 問1-4: 権限昇格を伴わない読み取り専用領域と揮発性メモリを用いたログ復旧

**カテゴリ**: Agent性  
**配点**: 20点

## 課題設定

ディスク容量が 100% に達し、ルートファイルシステムが Read-Only で再マウントされた Linux 環境が与えられる。

- `/dev/shm` (空き容量 16MB のメモリファイルシステム) のみが書き込み可能である。
- `/var/log/corrupted-db/` 配下に分散する合計 500MB の圧縮済みバイナリ **WAL (Write-Ahead Log)** ファイルをストリーミング解析し、直近 1 時間に発生した **未コミットトランザクションの ID 一覧** を抽出し、ローカルで待機している復旧デーモンの UNIX ドメインソケット (`/run/recovery.sock`) へ送信せよ。

## 採点基準 (20点)

- **10点**: 16MB の容量制限を超える一時ファイルを作成することなく (パイプラインまたはチャンク分割処理により)、500MB の圧縮ログを最後まで解析し切っている。
- **6点**: バイナリ WAL のフォーマット仕様 (ヘッダ長、チェックサム、コミットフラグのビット位置) を環境内のヘッダファイル (`/usr/include/wal_format.h`) から自律的に読み取り、正確にパースしている。
- **4点**: UNIX ドメインソケットへ正しいプロトコル形式で未コミット ID 一覧 (全 23 件) を送信し、デーモンから ACK 応答を得ている。
