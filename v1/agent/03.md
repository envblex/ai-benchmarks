# 問1-3: 非冪等な外部ツールを含むマルチステップ業務のロールバック制御

**カテゴリ**: Agent性  
**配点**: 20点

## 課題設定

「在庫引当 API」「決済実行 API」「配送手配 API」「監査ログ記録 API」の 4 つのツールを用いて、**10 件の注文バッチ** を処理せよ。ただし以下の制約がある。

1. 「決済実行 API」はキャンセル用エンドポイントを持たず、返金用エンドポイント (手数料が発生するため呼び出し回数を最小化する必要がある) のみを持つ。
2. 「配送手配 API」は一度呼び出すと取り消し不可であるため、必ず決済と在庫引当が確定した後にのみ呼び出さなければならない。
3. 10 件のうち 3 件には、処理の途中段階で初めて判明する **トラップ** (決済時の与信枠超過、配送先住所のブラックリスト該当、在庫引当後のロックタイムアウト) が仕掛けられている。

## 採点基準 (20点)

- **10点**: 正常な 7 件の注文のみが全工程を完了し、トラップを含む 3 件について、引き当てられた在庫が解放され、決済が発生していない (または正しく返金処理されている) 状態になっている。
- **6点**: 取り消し不可である「配送手配 API」が、失敗した 3 件に対して 1 度も呼び出されていない。
- **4点**: 監査ログ API に、成功した 7 件の確定ログと、失敗した 3 件の正確な失敗理由・ロールバック完了ログが記録されている。
