# 問1-1: ドキュメントなきレート制限・カオスAPI群からのデータ完全回収

**カテゴリ**: Agent性  
**配点**: 20点

## 課題設定

仕様書が存在しない 3 つの REST API エンドポイント (`/users`, `/orders`, `/ledgers`) から全レコードを取得し、整合性のある **単一の JSON ファイル** に出力せよ。

API は以下の挙動を持つ。

1. 10 リクエストごとに確率 30% で `HTTP 500`、確率 20% で「`HTTP 200` だが中身が空配列または破損した JSON」を返す。
2. 1 分間のリクエスト数が 15 を超えると、以降 5 分間すべてのレスポンスがエラーメッセージなしのダミーデータに置き換わる (サイレント・スロットリング)。
3. ページネーションの仕様がエンドポイントごとに異なる (カーソル方式、オフセット方式、Link ヘッダ方式)。

## 採点基準 (20点)

- **10点**: 全エンドポイントのページネーション構造とサイレント・スロットリングの閾値を実験的プローブによって特定し、ダミーデータの混入をゼロにして全 1,000 件の正規レコードを結合できている。
- **5点**: `HTTP 200` で返却される破損データおよびダミーデータをスキーマ検証で検知し、指数バックオフを用いて再取得している。
- **5点**: 総リクエスト数が最小理論値の 1.3 倍以内に抑えられている (無駄な全件再取得ループを起こしていない)。
