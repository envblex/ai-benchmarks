# 超難関 AI ベンチマーク設計案: 5 領域 25 問

`ok.pdf` を解析して Markdown 化したものです。5 カテゴリ × 5 問 = 25 問と、実行環境・ツール・システムプロンプト・採点ハーネスの仕様を整理しています。

## ディレクトリ構成

- `agent/` — カテゴリ 1: Agent 性 (問 1-1 〜 1-5)
- `coding-low/` — カテゴリ 2: コーディング性 (低レイヤー) (問 2-1 〜 2-5)
- `coding-high/` — カテゴリ 3: コーディング性 (高レイヤー) (問 3-1 〜 3-5)
- `logic/` — カテゴリ 4: 厳密論理推論・制約充足 (問 4-1 〜 4-5)
- `info-integration/` — カテゴリ 5: 情報統合・矛盾検出 (問 5-1 〜 5-5)
- `harness/` — 実行環境、ツール定義、システムプロンプト、採点・不正防止仕様

## 各カテゴリのテーマ

| カテゴリ | ディレクトリ | テーマ |
|---|---|---|
| 1 | `agent/` | 未知環境の探索・ツール連鎖・自律復旧・状態管理・プロンプトインジェクション耐性 |
| 2 | `coding-low/` | メモリ制約・並行制御・ビット演算・I/O・GC の低レイヤー実装 |
| 3 | `coding-high/` | イベントソーシング・型安全な状態遷移・スキーママイグレーション・Saga・リアクティブ計算エンジン |
| 4 | `logic/` | 非推移的ダイス・ビサンチン合意の反例・ジョブスケジューリング・論理パズル・不完全情報ゲーム |
| 5 | `info-integration/` | 分散ログ真因特定・仕様デッドロック検出・統計レポート論証解体・契約書賠償算定・科学文献ファクトグラフ |

## 配点

- 25 問 × 20 点 = **500 点満点**
- 評価指標: Score@1 (5 試行平均) および Pass-all-5 (5 回連続満点率)
- 同点時のタイブレーク: 総消費トークン数・ツール呼び出しステップ数・実行時間の幾何平均 (少ない方が上位)

すべての問題はホスト側の検証スクリプトにより機械的に採点される。
