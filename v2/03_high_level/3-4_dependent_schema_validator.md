# 問3-4：依存フィールド制約付きスキーマバリデータと多言語エラーツリー生成

## 1. 課題設定
動的なフォーム入力JSONを検証するバリデーションエンジンを実装せよ。
* 相互依存ルール：
  1. `account_type == "CORPORATE"` の場合のみ `corporate_number`（13桁数字）が必須。
  2. `delivery_date` は `order_date` より2営業日（土日祝を除く）以降。
  3. `items` 内の各要素について、`discount_price` は `unit_price` 以下。
* エラー発生時は、フィールドパス（例：`items[2].discount_price`）と指定言語（`ja` / `en`）に応じたエラーメッセージツリーをJSONで出力せよ。

## 2. 採点基準（20点満点）
* **8点**：相互依存バリデーション（法人番号、営業日計算、割引価格）の境界値テストが全件Passする。
* **6点**：エラーメッセージツリーが指定されたJSONスキーマ構造に完全一致する。
* **6点**：言語切り替え（`ja` / `en`）およびプレースホルダー置換が正確に動作する。
