# 問3-2：サーキットブレーカー（Circuit Breaker）パターンのスレッドセーフ実装

## 1. 課題設定
不安定なマイクロサービス呼び出しをラップし、障害の連鎖（雪崩）を防ぐ `CircuitBreaker` クラスを実装せよ。
* 状態：`CLOSED`（通常）、`OPEN`（遮断中）、`HALF_OPEN`（試験回復中）。
* 動作仕様：
  1. `CLOSED` 時に、直近 $N$ 回の呼び出しの中で失敗率が $P\%$ を超えた場合、即座に `OPEN` に遷移する（スライディングウィンドウ方式）。
  2. `OPEN` になると、外部関数は呼び出されずに即座に `CircuitOpenError` を投げる。
  3. $T$ 秒のクールダウン時間が経過すると `HALF_OPEN` に遷移し、次の1回（または指定試行数）だけ実際の外部関数を実行する。成功すれば `CLOSED` に復帰し、失敗すれば再び `OPEN` に戻る。

## 2. 採点基準（20点満点）
* **8点**：状態遷移（CLOSED → OPEN → HALF_OPEN → CLOSED / OPEN）の単体テストをすべてPassする。
* **6点**：スライディングウィンドウの計算が正確で、古い過去のエラーが現在の判定に影響を与えない。
* **6点**：複数スレッドから同時に呼び出された際、`HALF_OPEN` で許可されるプローブ試行が指定回数を超えてリークしない。
