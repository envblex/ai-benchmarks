# 問3-3：補償トランザクション（Sagaパターン）を伴うオーケストレーション型ワークフロー

## 1. 課題設定
マイクロサービス間の分散トランザクションを調整するSagaオーケストレーターを実装せよ。
* ワークフローは4ステップ：
  1. `ReserveInventory` / 補償：`ReleaseInventory`
  2. `ApplyCoupon` / 補償：`RevertCoupon`
  3. `ProcessPayment` / 補償：`RefundPayment`
  4. `CreateShipment` / 補償：`CancelShipment`
* 途中のステップで例外が発生した場合、それまでに成功したステップの補償トランザクションを逆順（LIFO）で確実に実行せよ。
* 補償トランザクション自体がネットワーク一時エラーで失敗した場合は、最大3回エクスポネンシャルバックオフでリトライせよ。

## 2. 採点基準（20点満点）
* **8点**：全ステップ成功時に全リソースがコミット状態になる正常系テストがPassする。
* **8点**：ステップ3（決済）で例外が発生した際、ステップ2→ステップ1の順序で過不足なく補償関数が呼び出される。
* **4点**：補償処理の一時失敗に対してリトライが機能し、最終的なSaga Logがスキーマ通りに出力される。
