# 問5-2：分散トレーシングログからのサイレントデータ破損イベントの特定

## 1. 課題設定
マイクロサービス群のOpenTelemetryトレースログ（約1,000スパン）が与えられる。
HTTPステータスコードはすべて `200 OK` を返しているが、ある特定のリクエスト経路でのみペイロードの暗黙的な型変換（浮動小数点数の丸め誤差による1円のズレ）が発生している。
トレースID、スパンID、入出力パラメータの数値を追跡し、データ破損が混入した最初のスパンIDと発生箇所を特定せよ。

## 2. 採点基準（20点満点）
* **10点**：データ破損が発生したスパンIDとサービス名を正確に特定している。
* **10点**：破損前と破損後の数値差分および発生要因（丸め処理）を正しく指摘している。
