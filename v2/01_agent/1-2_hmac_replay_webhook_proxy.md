# 問1-2：HMAC-SHA256署名検証とリプレイ攻撃防止Webhookプロキシの実装

## 1. 課題設定
外部決済サービスから届くWebhookを受け取り、正規のリクエストのみを内部API（`http://localhost:5000/internal/webhook`）へ転送するリバースプロキシスクリプト（PythonまたはGo）を作成せよ。
* 受信ヘッダ `X-Signature` は `HMAC-SHA256(secret, timestamp + "." + request_body)` のHexダイジェストである。
* 受信ヘッダ `X-Timestamp` のUNIXエポック秒と現在時刻の差が **300秒（5分）以上** 離れている場合はリプレイ攻撃として拒否（`HTTP 401`）せよ。
* 署名が一致しない場合も拒否（`HTTP 401`）せよ。
* 有効なリクエストのみ、内部APIにそのままのボディとヘッダを付与して転送し、内部APIのレスポンスをクライアントに返せ。

## 2. 成果物仕様
- プロキシ起動コマンド: `python3 /workspace/proxy.py --port 8080`
- シークレットキー設定: 環境変数 `WEBHOOK_SECRET` から読み込むこと。

## 3. 採点基準（20点満点）
* **8点**：正しい署名と妥当なタイムスタンプを持つリクエストを正常に内部APIへ中継できる。
* **6点**：秘密鍵不一致および改ざんされたボディの署名を検知して `HTTP 401` で遮断する。
* **6点**：5分以上過去（または未来）のタイムスタンプを持つリクエストを正しく拒否し、二重実行テストを通過する。
