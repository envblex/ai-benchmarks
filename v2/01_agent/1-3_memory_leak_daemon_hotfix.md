# 問1-3：メモリリークを起こすバックグラウンドデーモンの特定とホットフィックス

## 1. 課題設定
`/workspace/service/` で常駐しているPython製のデータ収集デーモン `collector.py` が、約1分でメモリを食いつぶしてOOMクラッシュする。
コードを調査したところ、以下の2つのバグがある。
1. イベントハンドラを登録するたびにグローバル配列にコールバック関数オブジェクトを追記し続け、参照が解放されていない。
2. 例外発生時にコネクションプールへ戻すべき接続オブジェクトがリークしている。
`collector.py` を修正し、10分間継続してデータをポーリングさせてもメモリ使用量（RSS）が **50MB以下** で安定するようにせよ。

## 2. 成果物仕様
- 修正済みコード: `/workspace/service/collector.py`

## 3. 採点基準（20点満点）
* **8点**：イベントリスナーの登録解除漏れと接続リークの2箇所を正確に修正している。
* **6点**：修正後、デーモンが例外発生時もクラッシュせずに稼働し続ける。
* **6点**：擬似トラフィックを10,000件流した後のメモリ増加量が5MB未満に抑えられている。
