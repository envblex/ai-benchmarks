# 問2-3：アライメント跨ぎビットパッキングと可変長RLE圧縮・展開器

## 1. 課題設定
リソース制約のあるマイコン向けバイナリシリアライザを実装せよ。
* 入力：0〜15の整数（4ビット値）の配列。
* **圧縮アルゴリズム**：
  1. 同じ値が連続する場合、最長16個までを「ヘッダ（4bit：値）＋ カウント（4bit：連続数-1）」の1バイトにまとめる（RLE）。
  2. 連続しない単発の値は、奇数個・偶数個を問わず4ビットずつ隙間なくビットパッキングしてバイト列に詰める。
* 圧縮関数 `compress(data: list[int]) -> bytes` と 展開関数 `decompress(raw: bytes) -> list[int]` を実装せよ。

## 2. 採点基準（20点満点）
* **8点**：ビットシフトやマスク処理でアライメント（バイト境界）跨ぎのパッキング・アンパッキングが正確に行われている。
* **6点**：RLEと単発値が混在する複雑なパターンのラウンドトリップ（`decompress(compress(x)) == x`）が100%一致する。
* **6点**：破損データ（ビット長が合わない、ヘッダ不正）が渡された際にパニックせず、適切な例外（`CorruptedDataError`）を投げる。
