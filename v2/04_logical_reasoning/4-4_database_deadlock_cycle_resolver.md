# 問4-4：データベースのデッドロック検出グラフからの最小コストトランザクション中断選定

## 1. 課題設定
RDBMSのロック待機グラフ（有向グラフ）内に複数の循環（デッドロック）が発生している。
各トランザクションには「すでに実行したクエリ数（中断コスト）」が設定されている。グラフ内のすべての閉路（Cycle）を解消するために、中断すべきトランザクションIDの集合のうち「合計中断コストが最小となる組み合わせ」を求めよ（Feedback Vertex Set問題の実務適用）。

## 2. 採点基準（20点満点）
* **10点**：選定されたトランザクションを除去した残りのグラフに閉路（デッドロック）が一切残らない。
* **10点**：中断されたトランザクションのコスト合計が理論上の最小値である。
